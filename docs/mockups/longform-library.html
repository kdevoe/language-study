What this demonstrates

  1. 1
    Same card language as the news feed — bg-card, 24px radius, uppercase source tag, serif title. One flat list; in-progress works sort to the top with a thin progress line along the card's bottom edge.
  2. 2
    Filter tabs actually filter — すべて / インポート / 雑誌 swap what the single list shows. No shelves, no sub-sections.
  3. 3
    Status lives in the card corner, like READY on news cards today: reading position (第2部 / 全4部), preparing spinner, or ✓ READY.
  4. 4
    The + button is the entire BYOC UI — paste or URL, with a live character count → part estimate before committing. Try typing in the paste box.
  5. 5
    Works persist — no swipe-to-dismiss; archive/delete would live on long-press or in the card (not shown). Magazine features (雑誌) only process when you choose one.
