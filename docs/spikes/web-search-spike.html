What I'd do

  • Keep RSS for the daily news feed. It's free, the outlets are hand-picked, and search is less reliable on exactly the big outlets we use: CNBC and Japan Times articles blocked web fetch, so 1 of 6 news runs failed outright and 1 fell back to a second-hand source. ~10× the rewrite cost for a feed that already works isn't worth it.

  • Use search where RSS can't help: free-text topics (deferred in #10 because Google News links weren't readable), long-form discovery (the Phase C "magazines" source that was never built), and grounded podcast briefs instead of from-scratch "topic" episodes. These are occasional, so the per-item cost stays small.
  • Haiku, not Sonnet, for picking and briefs. Add a cleanup step either way: fetched pages arrive as markdown with menus and footers (both tools do this), so the lead-paragraph extraction still matters.
